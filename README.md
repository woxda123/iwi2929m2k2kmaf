# 🎭 Wox Mafia — Telegram-бот для игры в Мафию

Клон функционала True Mafia. Бот-ведущий для групповых игр: кнопки, эмодзи,
ночные ходы в личке, живое голосование, магазин, профиль и рейтинг.

## 🚀 Установка

1. Создай бота у @BotFather, получи токен.
2. Установи зависимости (Python 3.12):
   ```
   pip install -r requirements.txt
   ```
3. Скопируй `.env.example` в `.env` и впиши токен:
   ```
   BOT_TOKEN=твой_токен
   ```
4. Запусти:
   ```
   python bot.py
   ```

## 🎮 Как играть

1. Добавь бота в группу и дай права администратора (удаление сообщений).
2. Напиши в группе `/game` — откроется набор с кнопками.
3. Игроки жмут **«➕ Присоединиться»** и нажимают **Start** у бота
   (так бот сможет писать им роли в личку).
4. Ведущий жмёт **«▶️ Начать сейчас»** (или `/start` в группе), либо игра стартует по таймеру.
5. 🌙 Ночью активные роли ходят кнопками в личке с ботом (мафия может переписываться там же).
6. ☀️ Днём — обсуждение, затем 🗳 голосование кнопками с живым подсчётом голосов.

## 📋 Команды

| Команда | Что делает |
|---|---|
| `/game` | 🎮 начать набор в игру |
| `/start` (в группе) | ▶️ досрочный старт (ведущий/админ) |
| `/stop` | 🛑 остановить игру (ведущий/админ) |
| `/leave` | 🚪 выйти из игры |
| `/profile` | 👤 профиль, инвентарь, звание |
| `/shop` | 🛒 магазин |
| `/top` | 🏆 топ-10 игроков |
| `/roles` | 🎭 описание ролей |
| `/help` | 📖 правила |

## 🛒 Магазин

- 🛡 **Защита** — 100 💰: спасает от одного ночного убийства
- 🎭 **Фейк ID** — 200 💰: комиссар один раз увидит тебя мирным
- ⚡ **Активная роль** — 500 💰: вместо мирного жителя получишь активную роль
- 💎 Гемы можно обменять на монеты

Монеты и гемы начисляются за игры (победителям — больше).

## 🗂 Структура

```
bot.py            точка входа
config.py         настройки, таймеры, цены магазина
database.py       SQLite (профили, игры)
game_logic.py     класс Game: роли, ночь, голосование, победа
roles.py          роли, эмодзи, описания
keyboards.py      inline-клавиатуры
utils.py          безопасная отправка/редактирование
handlers/         start, game, profile, night_actions
texts/ru.json     все тексты
```

## ⚠️ Важно

- Активные игры хранятся в памяти; после перезапуска бота идущие партии сбрасываются.
- Бот не может писать пользователю первым — игроки обязаны нажать **Start** у бота.
- Для удаления сообщений ночью/мёртвых игроков нужны права админа.
- Таймеры и настройки — в `config.py`.
